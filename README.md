# 词意

Koishi 群聊猜词插件。每天以一个两字词开局，玩家通过猜词继续对局。

## 安装

```sh
yarn add koishi-plugin-ciyi
```

在 Koishi 中启用，并安装 `database` 服务。图片输出需要 `canvas` 服务。

## 指令

| 指令 | 说明 |
| --- | --- |
| `ciyi` | 查看玩法 |
| `ciyi.猜 <词>` | 开始今日对局或提交猜测 |
| `ciyi.裸词 [开/关]` | 切换本频道无前缀续猜 |
| `ciyi.排行榜` | 查看累计猜中排行 |

开局后可直接发送两字词继续猜；也可在 @ 或引用消息后输入词语。裸词设置仅对当前频道有效，插件重载后恢复默认。

## 显示与交互

发送 `ciyi.显示 文字` 或 `ciyi.显示 图文` 切换个人显示偏好。同一机器人中的配套插件共享选择，重启后恢复图文。图文模式中的信息图片附带文字说明；作品素材与感官测试的适用边界见 [设计系统](./DESIGN_SYSTEM.md)。

本次更新：图片同时保留文字线索与排行榜；修复奖牌数字对比度；裸词冲突保护。
